One original dating-app bio, a single line under 180 characters, written to `/output/entry.txt` for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty. A judge model plays the entries off two at a time until the funniest bio takes the $2 prize.

> My last date said I was 'too predictable' — I'd already predicted she'd say that, word for word, three days early. Looking for someone whose next move I can't compute.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
